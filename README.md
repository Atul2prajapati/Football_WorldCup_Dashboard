🏆 Interactive Football Dashboard
An interactive Power BI dashboard showcasing the performance of the top 20 national football teams based on FIFA World Cup 2022 statistics, with dynamic filters, historical insights, and player-level analysis.

📊 Features
Dynamic team selection: Explore stats for multiple national teams.

Match overview: Matches played, won, and current world ranking.

Upcoming fixtures: Integrated 2026 World Cup schedule.

Historical achievements: Wins and losses across World Cups.

Goals analysis: Contribution to total goals, attacking strength.

Player stats: Radar chart for passes, assists, goals, and touches.

Recent form: Last five match outcomes visualized.

⚙️ Data Pipeline
Web scraping: Pulled World Cup wins/loss data directly from Wikipedia using Python.

Data cleaning with Pandas: Filtered and structured the scraped data, then saved as CSV.

Power BI integration: Imported CSV files and additional datasets directly into Power BI.

Power Query: Fixed null values, applied filters, and transformed data.

DAX calculations: Created measures for advanced insights.

Image handling: Managed visuals using Base64 encoding and wiki-sourced CSV references.

🚀 Tech Stack
Python (web scraping, Pandas for data wrangling)

Power BI (visualization, Power Query, DAX)

CSV (data storage and transfer)

Base64 & Wiki CSV (image integration)

📌 Insights
This dashboard provides:

A comprehensive view of team performance across tournaments.

Comparisons between countries on wins, goals, and rankings.

Player-level analysis for deeper tactical insights.

A dynamic storytelling tool for football data enthusiasts.
